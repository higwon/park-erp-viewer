# Park ERP Viewer

Park Systems ERP의 근태 조회 응답을 감지해 오늘 상태, 주간 근무시간, 초과근무 및 퇴근 가능시간을 표시하는 Tampermonkey 사용자 스크립트입니다.

## 설치

1. Chrome 또는 Edge에 Tampermonkey를 설치합니다.
2. `park-erp-viewer.user.js` 파일의 Raw 주소를 엽니다.
3. Tampermonkey 설치 화면에서 설치합니다.
4. ERP 근무내역 화면에서 기간을 조회합니다.
5. 화면 오른쪽 아래의 `내 근태 보기` 버튼을 누릅니다.

## 계산 기준

- 실제 근무시간: 출근·퇴근 시각 기준
- 휴게시간: 장시간 근무 시 1시간 반영
- 유급근무시간: ERP 응답의 `PaidWkCnt` 사용
- 필요 근무시간: `8시간 - PaidWkCnt`
- 대체휴가·연차(일): `PaidWkCnt = 8`, 필요 근무시간 0
- 반차: `PaidWkCnt = 4`, 필요 근무시간 4시간
- 시간 연차: 예를 들어 `PaidWkCnt = 2`, 필요 근무시간 6시간
- 마지막 근무일: 이전 누적 근무시간을 반영해 당일 필요 근무시간 계산

## 주의

이 스크립트는 ERP가 정상적으로 받은 조회 응답을 브라우저에서 재가공해 표시합니다. ERP 인증을 우회하거나 서버 데이터를 수정하지 않습니다. 표시 결과는 참고용이며 공식 기록은 ERP 원본을 기준으로 확인해야 합니다.
